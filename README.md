# homeassistant-whatsapp

Iteology Home Assistant add-on repository.

## Install
1. Home Assistant → Settings → Add-ons → Add-on Store
2. Menu (⋮) → Repositories
3. Add: `https://github.com/cometrulz/homeassistant-whatsapp`
4. Install **Iteology WhatsApp**

Licensing is handled via `https://walicense.webeology.app`.
