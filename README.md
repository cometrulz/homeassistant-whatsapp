This Home Assistant WhatsApp add-on enables reliable message sending with planned support for receiving messages, media, and automation triggers. It is designed as a maintained, evolving solution rather than a one-time project, with ongoing improvements as WhatsApp changes. Future updates will include inbound message handling, command-based automation, and optional advanced features. The add-on follows a structured approach where messages can trigger Home Assistant events or automations. A small yearly fee helps fund continuous development, updates, and support to keep the integration stable and improving over time.

🚀 Future Development Roadmap

Planned features and improvements include:

Messaging Enhancements
	•	Send media (images, documents, and files)
	•	Improved message reliability and delivery handling
	•	Message templates and formatting support

Group Messaging
	•	Send messages to WhatsApp groups
	•	Group-specific configuration and targeting

Incoming Messages
	•	Receive incoming WhatsApp messages and media
	•	Expose incoming messages as Home Assistant events
	•	Support for both private chats and group messages

Automation & Commands
	•	Command-based control via WhatsApp (e.g. “gate”, “status”, “lights on”)
	•	Trigger Home Assistant automations from incoming messages
	•	Built-in basic commands (status, help, etc.)

Security & Access Control
	•	Whitelisted phone numbers (only approved users can send commands)
	•	Per-user and per-group permissions
	•	Optional confirmation for sensitive actions

Media Handling
	•	Receive and process incoming media (images, audio, documents)
	•	Use media within Home Assistant automations (e.g. snapshots, uploads)

Advanced Features (Planned)
	•	Two-way interaction between WhatsApp and Home Assistant
	•	Optional AI/LLM-based message interpretation
	•	Enhanced configuration and usability improvements

Stability & Maintenance
	•	Continuous updates to keep compatibility with WhatsApp changes
	•	Performance and reliability improvements
	•	Ongoing support and feature expansion


# homeassistant-whatsapp

Home Assistant add-on repository.

## Install
1. Home Assistant → Settings → Add-ons → Add-on Store
2. Menu (⋮) → Repositories
3. Add: `https://github.com/cometrulz/homeassistant-whatsapp`
4. Install **Iteology WhatsApp Connector**
