## 1) Home Assistant Community Forum post

**Title**
Iteology WhatsApp Connector (Home Assistant Add-on) — QR pairing, automation sends, annual licensing

**Body**
Hi everyone 👋

I’ve released **Iteology WhatsApp Connector**, a Home Assistant add-on for WhatsApp messaging with a simple setup flow.

### What it does
- Pair via QR from the add-on UI
- Send WhatsApp messages from HA automations/scripts
- Supports ongoing state monitoring and reconnect controls
- Built-in send/receive logging

### Install
1. Home Assistant → Settings → Add-ons → Add-on Store
2. 3-dots menu → Repositories
3. Add: `https://github.com/cometrulz/homeassistant-whatsapp`
4. Install **Iteology WhatsApp Connector**

### Licensing model
- 7-day trial (non-resettable per instance)
- $20/year per active instance
- Developer actively maintains compatibility updates when upstream changes happen

### Feedback
If you test it, I’d love feedback on onboarding, reliability, and feature requests.
